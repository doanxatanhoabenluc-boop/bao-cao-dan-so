Sao lưu & khôi phục dữ liệu
Sao lưu nhẹ cho tài khoản Free: hệ thống chỉ tạo file nén khi bạn bấm tải xuống, không chạy sao lưu nền và không lưu bản sao trên Render/Supabase. File gồm dữ liệu PostgreSQL của hệ thống (tài khoản, dân cư, 11 biểu mẫu, lịch sử, danh mục, nhật ký) và file tra cứu BHYT SQLite.
1. Tải bản sao lưu về máy

Tạo một file .jsonl.gz để bạn lưu trên máy tính hoặc ổ cứng riêng. Nên sao lưu định kỳ sau các đợt nhập liệu quan trọng.

2. Khôi phục từ file đã sao lưu

Cảnh báo: khôi phục sẽ thay thế dữ liệu hiện tại bằng dữ liệu trong file. Hãy tải bản sao lưu hiện tại trước khi thực hiện.

Bảo mật: file sao lưu có chứa thông tin dân cư và tài khoản đăng nhập. Chỉ lưu ở nơi an toàn, không gửi công khai. File tạo từ phiên bản CSDL khác có thể không khôi phục được nếu thiếu cấu trúc tương thích.
